# Four Branching Elemental Skill Trees

We decided to structure character and Beast abilities into four specialized elemental Skill Trees mirroring classic TS Online archetypes: Earth (defense, petrification, resurrection), Water (healing, freeze crowd control, revival), Fire (maximum physical ATK and INT magic burst), and Wind (AGI acceleration, invisibility, evasion). This enforces distinct tactical roles and team synergy over generic skill pools.
