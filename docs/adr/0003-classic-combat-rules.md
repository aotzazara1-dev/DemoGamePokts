# Classic TS Online Combat System Model

We adopted the core TS Online combat rules: 6 primary attributes (HP, SP, ATK, DEF, INT, AGI), a strict 4-element cycle (Earth > Water > Fire > Wind > Earth), a 2x5 formation grid per side with front-row melee blocking, and simultaneous 30-second action planning with AGI-based resolution and combo mechanics. This preserves tactical depth and player familiarity while accommodating an original creature theme.
